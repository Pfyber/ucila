## Using it in class

For many children, fractions are the first truly abstract idea in maths. But once they can literally lay a quarter on top of a half, "¼ is less than ½" stops being a rule and becomes something they can see and touch.

**Activity: "Who can build a whole circle?" (15 minutes, groups of 3–4)**

1. Each group gets a mix of pieces from all the discs. The whole red disc stays on the table as the "base".
2. The teacher says: *"Build a whole circle using only quarters."* Then: *"Now use one half and two quarters."* Then: *"One third and two sixths ... how much is still missing?"*
3. Groups write each build on a mini whiteboard as a sum, e.g. ½ + ¼ + ¼ = 1.
4. To finish, each group finds two different ways to write the same part of a circle (e.g. ¼ = ²⁄₈) and shows the class.

**Tip:** give slower groups only halves and quarters, and faster groups eighths and sixths together. They don't line up, which sparks a great discussion.

The included worksheet (`navodila.pdf`) works well as homework or a warm-up the next day.

## Build steps

{{% steps %}}

### Cut the sheet

Open `plosca.svg` in your laser cutter software. Red lines (0.01 mm) are cuts, blue text is engraving. One pass is usually enough for 3 mm poplar; test power and speed on an offcut first.

{{< figure src="step-1.jpg" alt="Plywood sheet in a laser cutter with six circles marked on it." >}}

### Sand and paint

Give the edges a quick sand so there are no splinters. Paint each disc a different colour, and leave half of the pieces bare wood – that makes it easier for children to count the "coloured" parts.

{{< figure src="step-2.jpg" alt="A disc split into quarters next to a paintbrush." >}}

### Test it in class

Check that all the pieces really make a whole circle. Put each set in a box or bag, one set per group.

{{< figure src="step-3.jpg" alt="Two discs on a table, one in quarters and one in eighths, with the text 1/4 = 2/8 below." >}}
