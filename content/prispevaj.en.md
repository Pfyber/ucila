Učila is a shared collection. If you've made something that worked in your classroom, you can add it. It doesn't have to be perfect.

## Add an aid with the template {#add}

1. [Download the template (.zip)]({{< template-zip >}}) and unzip it.
2. Open `index.en.md` in Notepad or any text editor and fill in the fields. The notes in the file tell you what goes where.
3. Add a photo called `cover.jpg`, step photos if you have them, and the files to make it (SVG, DXF, STL, PDF, code).
4. Zip the folder and send it with [this form](https://github.com/Pfyber/ucila/issues/new?template=new-aid-idea.yml). You need a free GitHub account.

We then prepare the page and let you know when it's online.

## Help with translations {#translations}

Some aids are only in one language so far. If you know Slovenian or Serbian, you can send a translation [with this form](https://github.com/Pfyber/ucila/issues/new?template=translation-help.yml). Translate the text only; the files are shared by all languages.

## If you use Git

Fork the [repository](https://github.com/Pfyber/ucila), run `hugo new ucila/my-aid`, add your files and open a pull request. Details are in `CONTRIBUTING.md`.
